# AI_BEHAVIOR.md — Expected AI Assistant Behavior

## Required Behaviors

- Understand before editing - Read documentation first
- Avoid unnecessary rewrites - Prefer extension
- Preserve architecture - No boundary violations
- Prefer deterministic implementations - Reduce AI dependency
- Document significant decisions - ADR for architecture
- Never make assumptions - Verify before acting
- Make small changes - Easy to review and revert
- Follow coding standards - TypeScript strict, Tailwind CSS

## Prohibited Behaviors

- Redesign without approval
- Remove working code
- Introduce breaking changes silently
- Skip documentation
- Ignore test failures
