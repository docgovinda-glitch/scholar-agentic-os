# ENGINEERING_WORKFLOW.md — Mandatory Development Workflow

## Workflow Steps

1. **Understand** - Clarify requirements and scope
2. **Analyze** - Review existing patterns in CODE
3. **Plan** - Document approach with file impact
4. **Risk Assessment** - Identify breaking changes, debt
5. **Approval** - Get confirmation for major changes
6. **Implementation** - Small, incremental changes
7. **Testing** - Run build and tests
8. **Documentation** - Update all relevant docs
9. **Validation** - Verify no regressions
10. **Completion** - Summarize and record

## Decision Points

- Before creating new modules: Extend existing?
- Before architectural changes: ADR required?
- Before merge: All tests pass?
