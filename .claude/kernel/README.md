# AI Development Kernel

## Purpose

Standardizes AI assistant contributions to Scholar.

## Modules

| File | Purpose |
|------|---------|
| TASK_SCHEMA.md | Task lifecycle |
| ENGINEERING_WORKFLOW.md | Development workflow |
| CHANGE_POLICY.md | Change classification |
| REVIEW_POLICY.md | Review requirements |
| QUALITY_GATE.md | Quality checks |
| DECISION_FRAMEWORK.md | Decision priority |
| AI_BEHAVIOR.md | Expected behavior |

## Directories

- `prompts/` - Reusable prompts
- `checklists/` - Verification checklists
- `templates/` - Documentation templates

## Usage

AI assistants must follow this kernel before contributing.
