# CHANGE_POLICY.md — Change Classification and Approval

## Change Types

| Type | Approval Required | Documentation |
|------|-------------------|---------------|
| Minor | None | Inline comments |
| Major | Review | ADR |
| Breaking | Explicit approval | Migration guide |
| Architecture | Mandatory ADR | Full docs update |

## Documentation Requirements

- Minor: Comments
- Major: ADR + README update
- Breaking: Migration guide + CHANGELOG
- Architecture: ADR + architecture docs + handover update
