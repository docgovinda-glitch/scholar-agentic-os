# REVIEW_POLICY.md — Review Requirements

## Required Answers

1. What changed?
2. Why was this change made?
3. Files modified?
4. Architecture affected?
5. Tests executed?
6. Documentation updated?
7. Risks identified?
8. Future work needed?

## Review Checklist

- [ ] Architecture preserved
- [ ] Tests added/updated
- [ ] Documentation current
- [ ] No regressions
- [ ] Code quality standards met
